Simulator VPC, Subnet, dan Aturan Firewall

Bab 9 — Virtual Private Cloud (VPC) dan Keamanan Jaringan

Cara main: Topologi VPC dengan 2 subnet dan beberapa VM sudah disiapkan di bawah. Nyalakan/matikan aturan firewall menggunakan kotak centang, lalu tekan tombol Uji pada tiap skenario lalu lintas untuk melihat apakah koneksinya diizinkan atau ditolak — beserta alasannya.
🌐 Internet (di luar VPC)

subnet-web (us-central1)

CIDR: 10.0.1.0/24
vm-web-1 tag: web
vm-web-2 tag: web

subnet-db (us-central1)

CIDR: 10.0.2.0/24
vm-db-1 tag: db

Aturan Firewall (Ingress)

allow-http-web Izinkan TCP:80,443 dari 0.0.0.0/0 menuju VM bertag web
allow-internal-web-to-db Izinkan TCP:3306 dari subnet-web (10.0.1.0/24) menuju VM bertag db
allow-ssh-admin Izinkan TCP:22 dari 0.0.0.0/0 menuju semua VM (tidak direkomendasikan untuk produksi)
deny-all-default Aturan implisit VPC: tolak semua ingress yang tidak cocok aturan allow manapun (selalu aktif)

Skenario Uji Lalu Lintas

1. Pengguna internet mengakses vm-web-1 lewat HTTP (port 80)
Belum diuji
2. vm-web-1 (subnet-web) menghubungi vm-db-1 lewat MySQL (port 3306)
Belum diuji
3. Pengguna internet mencoba akses langsung ke vm-db-1 lewat MySQL (port 3306)
Belum diuji
4. Administrator dari internet mencoba SSH (port 22) ke vm-web-2
Belum diuji
