Jaringan Komputer & Praktikum Jaringan Komputer

Media Pembelajaran Interaktif

Kumpulan 9 alat bantu visual/interaktif untuk melengkapi materi SPADA. Setiap alat berupa satu file HTML mandiri (tanpa dependensi eksternal) — bisa dibuka langsung di browser, di-embed di Moodle lewat resource URL/Page (iframe), atau di-hosting terpisah (mis. GitHub Pages) lalu ditautkan dari SPADA.

01 — Subnetting
Visualisasi VLSM
Pemotongan blok alamat IP langkah demi langkah berdasarkan kebutuhan host.
02 — Subnetting
Kalkulator Subnet (AND Biner)
Operasi AND biner bit-per-bit untuk menurunkan network address & broadcast.
03 — Keamanan & Routing
Simulator Urutan Aturan ACL
Paket diuji baris per baris hingga aturan pertama yang cocok (first-match-wins).
04 — Keamanan Jaringan
Animasi ARP & ARP Spoofing
Alur ARP normal vs serangan spoofing, dengan tabel ARP cache langsung.
05 — Layanan Jaringan
Animasi DHCP (DORA) & DNS
Proses handshake DHCP dan resolusi DNS rekursif/iteratif, langkah demi langkah.
06 — Perangkat & Topologi
Pemetaan Topologi via CDP
Membangun peta topologi bertahap dari data neighbor CDP tiap perangkat.
07 — Praktikum Kabel
Pembuat Wiremap RJ45
Susun pin T568A/T568B, validasi straight-through vs crossover.
08 — Diagnostik Jaringan
Animasi Traceroute (TTL)
TTL berkurang tiap hop dan balasan ICMP Time Exceeded, hop demi hop.
09 — CLI & Switching
Navigator CLI & Pembelajaran MAC Switch
Peta mode CLI Cisco yang bisa diklik, plus simulasi flood vs forward pada switch.
Dibuat sebagai materi pendukung (bukan pengganti) modul SPADA Jaringan Komputer & Praktikum Jaringan Komputer. Tidak memerlukan plugin Moodle apa pun — cukup file HTML statis. Untuk hosting di GitHub Pages: unggah seluruh folder ini ke repositori, aktifkan Pages, lalu tautkan index.html atau file masing-masing alat dari SPADA.
