Navigator Mode CLI Cisco & Simulasi Pembelajaran MAC Address oleh Switch

Alat bantu praktikum Jaringan Komputer — latihan interaktif untuk memahami mode CLI IOS dan cara kerja switch Layer 2.

Setiap perintah pada Cisco IOS hanya berlaku pada mode tertentu, sehingga penting memahami bagaimana kita berpindah antar mode. Klik salah satu tombol perintah di bawah untuk "menjalankan" perintah tersebut dan lihat bagaimana indikator mode aktif serta prompt terminal berubah. Diagram ini menampilkan enam mode utama beserta perintah yang menghubungkannya.

Mode Tantangan nonaktif

Sistem akan memberi target mode. Klik perintah yang menurutmu benar secara berurutan untuk mencapainya. Jika salah jalur, kamu tidak dianggap "gagal" — kamu hanya akan melihat ke mode mana perintah itu sebenarnya membawamu, lalu bisa lanjut mencari jalan yang benar.

Switch Layer 2 mempelajari alamat MAC dari frame yang masuk lalu menyimpannya pada tabel MAC (CAM table). Selama alamat MAC tujuan belum diketahui, switch akan flood (mengirim frame ke semua port kecuali port asal) — ini kurang efisien dan membuat host lain ikut melihat frame tersebut. Setelah MAC tujuan dipelajari, switch cukup forward (meneruskan) frame hanya ke satu port yang benar.
