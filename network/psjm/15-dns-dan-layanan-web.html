Membuktikannya sendiri di komputer Anda

PerintahYang dibuktikannya
nslookup www.ums.ac.id Tahap DNS: nama domain berhasil diterjemahkan menjadi alamat IP, dan resolver mana yang menjawab.
ping 203.0.113.25 Konektivitas ke alamat IP tujuan, terpisah dari persoalan penerjemahan nama.
tracert www.ums.ac.id Router mana saja yang dilewati paket menuju server tersebut.
ipconfig /displaydns Isi singgahan DNS pada komputer Anda sendiri, lengkap dengan sisa waktu hidupnya.

Bila ping ke alamat IP berhasil tetapi ping ke nama domain gagal, yang bermasalah adalah tahap DNS — bukan jaringannya.

Tiga hal yang perlu Anda perhatikan

  • DNS bekerja berjenjang, bukan sekali tanya. Root tidak mengetahui alamat www.ums.ac.id; ia hanya menunjukkan siapa yang mengurus .id. Begitu seterusnya sampai server otoritatif yang benar-benar menyimpan jawabannya.
  • Singgahan memangkas hampir seluruh perjalanan itu. Coba centang “Resolver sudah menyimpan jawabannya” dan bandingkan jumlah langkahnya. Nilai TTL pada jawabanlah yang menentukan berapa lama jawaban itu boleh disimpan.
  • Nomor port menentukan layanan, alamat IP menentukan host. Server yang sama dapat melayani HTTP di port 80 dan HTTPS di port 443 pada satu alamat IP, karena keduanya dibedakan oleh nomor port.
